# 任务、设置、历史与媒体输出合同

> 合同层级：现行合同。唯一领域正文由合同总入口注册；历史方案不能覆盖本页实现事实。

2026-10-12按当前实现统一；[总入口](contracts/README.md)、[注册表](contracts/registry.json)定位所有者与适用证据。

## 唯一事实与字段

Repository拥有队列/历史/吞吐写入；Room四表是媒体、任务、历史、吞吐报告。UI/Window不直接写DAO。SettingsRepository保存默认质量、输入草稿、目录、命名、网络恢复与并发任务设置；当前默认720p/并发1，支持并发1至3，具体枚举和值以SettingsRepository为准。播放位置独立于Room，见[播放合同](video-playback.md)。

普通阶段WAITING→PARSING→DOWNLOADING→VALIDATING→COMPLETED，经TaskTransitionPolicy；暂停、网络等待、失败、跳过、取消独立。批量恢复/暂停/取消走Repository专用DAO更新，不能假称每条SQL都调用同一状态函数。processingStage说明真实网络/合并/转换/分段/校验/发布，不改变终态定义。

身份/质量/分段设置共同影响重复与已有成品复用；图集历史还需来源认证及数量，URI可读性单独检查。历史删除按既有语义删记录、不删成品，允许重新下载；失效标记不等于删除文件。失败/取消原任务经重试恢复，不能用新入队掩盖旧失败。

## 处理与输出

TaskRunner解析→准备媒体→发布后归档。MP3为PCM/LAME真实编码；无损合并/关键帧分段与显式分辨率转码分开，不能把无损合同扩大为“永不转码”。媒体传输/样本约束见[传输合同](download-transfer-policy.md)。

MediaStore使用本次pending目标，SAF在用户目录创建文档；命名冲突新副本，不覆盖旧成品。写入前后结构/可读性校验、单次异常回滚本次新URI/文档；当前成功收束可删除任务私有准备文件，不是清用户缓存或删原成品。取消不能发布假完成，需同时验证终态与实际输出。

发布与Room归档先后执行，未形成跨系统事务；突然进程死亡、多输出或归档失败的完整恢复仍需独立验收，不由catch回滚推断。运行时结构预检也不代表每次逐帧解码证明全部内容完整。

## 迁移与验证

当前Room11，显式1→11迁移及schema；图集信任版本、捕获来源、收藏的默认值不能倒推旧记录可信。数据变更需entity/DAO/migration/schema/回归同时维护。收藏独立正文见[收藏合同](history-favorites.md)。

自动状态/迁移/取消/恢复与输出夹具、隔离正常UI/成品、主设备升级各自报告；旧文件/历史URI保留不等于所有字段逐列未变。审批、设备与数据安全只由根AGENTS和当前用户授权决定。
