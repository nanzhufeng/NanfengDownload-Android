# 历史视频收藏

> 合同层级：现行合同。唯一领域正文由合同总入口注册；历史方案不能覆盖本页实现事实。

2026-10-12复核；[总入口](contracts/README.md)为规范路由，[注册表](contracts/registry.json)列源码和验证。

- 收藏状态属于 `download_history.isFavorite`，默认 false；Room 10→11 只添加非空默认0列，不改原任务、输出URI、完成时间或文件。
- UI 只经 `DownloadRepository.setHistoryFavorite(taskId, desiredState)` 更新。保存成功后给反馈，失败不显示成功；使用指定目标状态避免重复调用翻转两次。
- 正常UI仅已完成视频可收藏：菜单等待本地媒体类型读取确认。Repository/DAO持久门禁是完成、非MP3、非已认证图集；这些字段不单独证明所有旧未知记录都是真视频。UI类型确认与持久字段门禁不能互相替代。
- 更多操作中的收藏/取消收藏、外部播放、复制、吞吐报告、分享、删除统一使用20dp图标。卡片用小星标表明已收藏。
- 平台、时间、收藏筛选与批量删除、清理失效共用同一横向行；空间不足时横向滑动，不再另起操作行，原业务回调与确认流程保持不变。
- 全部时间右侧的收藏筛选进入时清空关键词、平台和时间限制，显示所有收藏视频；随后可组合搜索/平台/时间筛选。筛选开关由自适应布局之外的共享可保存状态持有，宽窄屏切换不退出收藏视图。
- 取消收藏只改标记；删除历史按原确认流程删记录，收藏随记录删除，不删除成品。标记文件失效保留收藏；收藏视图隐藏会清理全体历史的全局失效清理按钮。
- 终态重复归档在事务中保留既有收藏标记，不能被工作线程默认值覆盖。
- 收藏入口由用户明确要求；设置不展示开发审阅，遵守根AGENTS的用户界面规则。

验证见 `verification/2026-10-11-history-favorites.md`。收藏不代表重新下载，也不修改播放器记忆或媒体发布规则。
