# 灵动岛反馈与字体规范

> 合同层级：现行合同。唯一领域正文由合同总入口注册；历史方案不能覆盖本页实现事实。

2026-10-12按当前实现复核；本文件是App内短反馈的现行正文，[总入口](../contracts/README.md)区分后台进度岛与历史方案。

范围：替换已有复制、会话操作、播放错误及下载完成提示，不添加常驻按钮，不改变主页、历史、设置的整体主题。

- 单一渲染器 `core/ui/IslandFeedback.kt`；应用内浮层，不请求悬浮窗权限。窗口不抢焦点、不遮暗背景、不改变原页面布局。需要用户确认的删除、安全与设置弹窗保留原交互。
- 短反馈按实际文字宽度伸缩；长反馈使用标题与正文两层，正文完整保留并可滚动。手机宽度保留外侧留白，大屏宽度上限464dp，内部14–18dp间距。
- 墨色轻渐变、同轮廓裁切与水波纹、柔和阴影；成功薄荷绿、错误暖红、信息暖橙。图标使用矢量资源，不用系统字体字符模拟。
- Noto Sans SC原始可变字体本地嵌入，标题550、正文400字重；15.5sp/13.5sp、自然行距，遵从系统字体缩放。字体后台加载；异常退回系统字体，不阻断下载。原字体及OFL许可证保留于assets/fonts。
- 复用IslandMotion的360ms原位淡入/缩放、轻微回弹，150ms退出；关闭系统动画时立即呈现。阅读时间根据内容与系统无障碍设置调整。触摸正文暂停计时，结束后重新计算完整阅读窗口。
- 点击提示可关闭，点击提示外的控件继续正常操作并关闭浮层。连续提示替换时，旧计时器不能关闭新提示。Activity暂停、停止或销毁时清理其窗口；不在后台弹浮层。
- 登录Activity结束后，由回到的应用Activity显示结果；过期结果不再次显示。下载完成只观察真实COMPLETED历史、非零可读成品及URI，不修改业务状态。不为旧历史、失败、取消或缺失成品报告新完成。
- 自动门禁、模拟器实际排版与主设备显示分别验收。无障碍属性与字号支持不代替真实TalkBack验收。

代码所有者与证据路径见[注册表](../contracts/registry.json)。360ms取自当前IslandMotion，不再沿用旧220ms设计值；后台岛字体/几何单独维护，不将不同场景误判为冲突。

许可证来源：[Google Fonts Noto Sans SC OFL](https://raw.githubusercontent.com/google/fonts/main/ofl/notosanssc/OFL.txt)。没有修改字体本体。
