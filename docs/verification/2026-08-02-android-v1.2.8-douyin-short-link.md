# Android v1.2.8 抖音短链接下载修复

日期：2026-08-02（Asia/Shanghai）

## 问题与根因

原问题链接 `https://v.douyin.com/R37NZ1wqjiM/` 能被识别为抖音，但进入 Python 解析层后仍以短链接交给 yt-dlp。既有 `_resolve_known_short_link` 没有覆盖 `v.douyin.com`，因此解析落入 Generic 分支并返回没有可下载格式。

## 修复语义

- 抖音短链接通过受控请求取得最终跳转地址。
- 最终 host 必须属于 `douyin.com` 或 `iesdouyin.com`；非官方跳转直接拒绝。
- 从 `/share/video/<id>` 或 `/video/<id>` 提取作品 ID，统一转换为 `https://www.douyin.com/video/<id>`。
- 抖音请求补齐站点 Referer 后再进入统一 yt-dlp 解析链。
- WebView 媒体捕获只作为短时兜底；捕获结果仍必须进入统一发现、去重、队列、传输、校验、发布和历史链路。
- 默认界面继续显示中文问题与可执行建议，原始底层错误只进入高级诊断。
