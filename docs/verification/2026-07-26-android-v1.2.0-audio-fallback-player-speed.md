## 目标

1. 资源没有独立音频格式时，“仅音频 MP3”仍能从含音轨视频生成真实 MP3。
2. 修复 YouTube 独立音频在多个 Range 连接互相争抢时极慢的问题。
3. 历史音频点击左侧封面直接使用 App 内置播放器，不默认打开第三方播放器选择器。

## 实现合同

- 音频来源优先级：独立音频流 → 最高不超过 720p 的含音轨渐进视频 → 未知尺寸含音轨视频 → 最小的更高分辨率含音轨视频。
- 任何视频回退都必须有音轨；视频无音轨时返回中文问题和解决建议。
- YouTube 独立音频使用单连接、1 MiB 顺序 Range；视频来源仍使用 YouTube 视频多连接策略。
- 下载阶段显示真实速度、已下载量和连接模式；转码阶段显示“正在提取音频并生成 MP3”，不把 CPU 编码误报成网络慢速。
- 历史音频封面打开内置 `MediaPlayer` 对话框，提供自动播放、播放/暂停、进度、当前时间、总时长和关闭；外部播放器为次要操作。
