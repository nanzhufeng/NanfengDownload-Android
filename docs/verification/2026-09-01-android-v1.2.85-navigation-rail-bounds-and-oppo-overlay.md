# Android v1.2.85 侧栏边界修正与 OPPO 覆盖安装验证

日期：2026-09-01（Asia/Shanghai）

## 修复事实

v1.2.84 试图让三个侧栏入口在导航栏内垂直居中，但 `NavigationRail` 没有固定横向宽度，内部 `Box.fillMaxSize()` 因而按外层可用宽度测量并撑满整个屏幕。用户提供的 OPPO 截图确认右侧内容被挤走、入口组错误地相对整屏居中。

v1.2.85 在 `PrimaryNavigationRail` 上加入 `.width(80.dp)`。内部填满尺寸和 `Alignment.Center` 现在只发生在 80dp 左栏范围内：顶部应用图标仍位于左栏顶部，三个入口只在左栏的纵向可用高度中居中；紧凑底部导航没有改动。
