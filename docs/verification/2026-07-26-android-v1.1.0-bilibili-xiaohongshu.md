## 产品范围

- 新增哔哩哔哩与小红书/Rednote 单视频链接识别、短链解析、去重、下载列表、传输、MediaStore 发布、历史记录、平台图标和永久吞吐报告。
- 哔哩哔哩公开视频支持独立视频流与音频流下载、合并；使用平台要求的页面来源和媒体请求头。
- `b23.tv` 在系统 DNS 或代理返回证书不匹配节点时，App 会通过 Cloudflare/Google 可信 DNS 获取候选地址并保持严格 TLS 校验；最终跳转不是官方 `bilibili.com` 域名时拒绝读取。

- 哔哩哔哩 UP 主页批量接口当前在真实网络中返回 412，`v1.1.0` 不声明支持该能力。主页链接会直接提示打开具体视频并重新分享。
- 不绕过会员、付费、DRM、私密或平台访问控制。

## 会话与界面

- 设置页按长视频/短视频分组展示五个平台，哔哩哔哩与小红书使用独立图标。
- 哔哩哔哩官方 H5 手机号登录页可正常打开；登录 Cookie 仍需在实际受限内容使用时再次验证。
- 小红书消费者网站没有稳定的独立移动网页登录入口；失效的 `/login` 页面已移除。当前支持范围为公开单视频免登录，设置页使用不可点击的“无需登录”，不保留假登录按钮。
- 默认界面只显示中文问题与可执行解决办法；原始底层错误继续保留在高级详情。
- 历史页把当前平台和时间筛选收进同一行的两个菜单按钮；外屏不再为平台、时间选项各占一行，时间线获得更多首屏高度。
