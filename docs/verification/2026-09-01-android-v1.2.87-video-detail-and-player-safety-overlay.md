# Android v1.2.87 视频详情面板与播放器安全区验证

日期：2026-09-01（Asia/Shanghai）

## 本次范围

- 历史页媒体详情由默认 `AlertDialog` 改为自定义 `Dialog` + 白色 `Surface`。面板限宽 600dp、最高 620dp，内容可滚动；头部包含媒体类型图标、标题与关闭入口，作品元信息集中在浅色信息面板中，避免展开屏出现大面积无意义空白。
- 详情操作按真实既有回调重排：可播放媒体保留“内置播放器播放／查看图片”主按钮；视频保留“选择播放器／用外部播放器打开”；“复制原链接”和有报告时的“查看吞吐报告”都保留。操作各自使用播放、打开、复制和报告图标，未新增下载、导出或其他业务能力。
- `InternalVideoPlayerOverlay` 的 `PlayerView` 现在使用 `statusBarsPadding()`：视频画面不进入顶部系统状态栏，状态栏区域由外层黑色背景承托。标题／关闭控制仍位于状态栏下方并和 Media3 控制条共用显隐状态。
- `PlayerView` 使用 `GestureDetector` 接收双击，在 `player.playWhenReady` 与 `pause()`／`play()` 间切换；触摸监听返回 `false`，因此事件仍交给原生播放器处理单击控制条和其他既有手势。
