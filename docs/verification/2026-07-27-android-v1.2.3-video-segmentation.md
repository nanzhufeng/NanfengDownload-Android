## 验收目标

- 等待中的视频任务可选择 1–20 段，默认不分段。
- 视频只下载、必要时合并一次，再无损生成多个可独立播放的 MP4。
- 历史只保留一条聚合记录，并显示完整总时长、总大小和段数。
- 网络字节完成不等于任务完成；任何未完成任务都不得显示 100%。
- 正式 APK 同签名无损覆盖 OPPO，不卸载、不清数据。

## 实现合同

- `VideoSegmentPlanner` 按目标时间选择最近的安全关键帧，输出连续的近似等长范围。
- `VideoSegmenter` 使用 `MediaExtractor + MediaMuxer` 无损转封装，保留视频、音频与方向。
- 分段过程不重新下载、不重复合并、不重新编码；所有目标文件验证通过后才删除中间成品。
- 关键帧不足时保留失败任务，并给出“减少分段数量”的中文建议。
- Room v6 的 `audioSegmentCount` 作为兼容历史字段承载通用媒体段数；本轮不做破坏性列改名。
- MediaStore 每段单独发布，文件名含“第 XX 段，共 N 段”；历史通过 URI 列表聚合。
