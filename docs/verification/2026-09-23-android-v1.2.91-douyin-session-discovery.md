# Android v1.2.91 抖音会话与作品发现验证

日期：2026-09-23（Asia/Shanghai）
范围：用户提供的抖音公开分享文本及 `https://v.douyin.com/qiRt29Dauu4/`；不代表其他作品或私有内容。

## 问题与证据

- 用户已在抖音登录，但南枫下载设置页显示“已检测到登录 Cookie，使用时仍会验证”，首页读取同一抖音作品却提示需要新网页会话、要求重新登录。Cookie 存在和网页请求通过账号校验是两个不同状态；现有截图不能证明 Cookie 丢失。
- 短链 HTTP 跳转及 `resolve_source` 实测落到 `https://www.douyin.com/video/7686854662317722889`。旧 `resolve_source`／`PlatformSourceDiscoveryEngine` 对这一官方作品页调用 yt-dlp，`fresh cookies` 异常先于已有 WebView 目标页捕获，被用户错误消息表现为重新登录。
- 第一轮隔离模拟器正常首页路径验证还发现第二个缺陷：视频页缺少可捕获视频元素时，封面图可进入图集后备路径。临时诊断显示目标作品 ID 和页面匹配，但 `videoValid=false`、`imageCount=1`、`expected=0`；此时封面不是完整媒体结果。临时诊断代码已移除。

## 修复范围

- 官方 HTTPS 抖音 `/video/<数字>`、`/note/<数字>` 及对应 `/share/` 作品页绕过 yt-dlp，直接使用既有目标页捕获；短链仍先解析。图文目标页的严格图集校验保留。
- 视频作品页禁止仅凭页面封面触发图集后备完成；未找到视频流时给出明确的网页／会话待检查提示，不制造下载任务。
- 已检测到认证 Cookie 时，设置页入口显示“查看账号”，并先打开账号页供人工核对；无认证 Cookie 时仍走登录页。此入口不宣称 Cookie 已经通过平台校验。

## 尚待用户真机验证

在 OPPO 上手动打开南枫下载，进入“设置 → 账号与权限 → 抖音 → 查看账号”，确认网页内仍是预期账号；返回首页重新读取上述链接，确认能否解析并完成视频下载。若账号页实际退出、平台挑战或目标页不返回视频流，应记录当前页面和精确提示，再区分会话失效与平台媒体捕获变化。仅凭此次构建、模拟器和覆盖安装，不能宣称已登录真机的下载闭环完成。
