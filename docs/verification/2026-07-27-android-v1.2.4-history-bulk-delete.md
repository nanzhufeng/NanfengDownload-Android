# 南枫下载 Android v1.2.4 历史批量删除验收

日期：2026-07-27（Asia/Shanghai）

## 目标与边界

- 在历史页增加可发现的批量删除入口。
- 常态不新增第二行工具栏；只有进入选择态后才显示“已选 / 全选 / 取消 / 删除”。
- “全选”只作用于当前搜索与平台、时间筛选后的可见历史。
- 删除只移除 App 内历史记录，不删除已经写入系统 MediaStore 的音视频文件。
- OPPO 保存着真实用户历史，本轮真机不得执行确认删除；破坏性结果由隔离的模拟器数据库验证。

## 实现事实

- `DownloadRepository.deleteHistoryRecords()` 是批量删除的公开入口。
- `RoomDownloadRepository` 先对任务 ID 去重，空集合直接返回；非空集合使用一次 `DELETE ... IN (...)`。
- 历史页保存临时选择状态，确认后一次提交 ID 列表；取消会清空选择并恢复原时间线。
- 分段音频和分段视频仍只对应一条聚合历史记录，批量选择不会拆散分段成品。
