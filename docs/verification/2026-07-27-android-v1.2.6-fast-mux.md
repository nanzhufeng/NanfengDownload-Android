# Android v1.2.6 音视频快速合并验收

日期：2026-07-27（Asia/Shanghai）

## 目标

缩短独立音视频下载完成后的本地合并等待，同时保持原始编码、画质、音质、取消语义、完整性校验和真实进度。

## 实现

- 删除基于 Media3 Transformer 的合并路径。
- 新增 `AndroidMp4TrackMuxer`，用 `MediaExtractor + MediaMuxer` 直接复制压缩轨道。
- 视频与音频样本按 presentation timestamp 交错写入，不执行解码或重新编码。
- 支持取消；失败或取消时删除未完成输出。
- 新增 `MERGING` 阶段与 0–99 合并进度，只有校验、MediaStore 发布和任务完成后才显示 100%。

## 性能对比

同一台开发机、同一份约 5 分钟、33,830,538 B 的 H.264 + AAC 输入：

| 实现 | 耗时 |
|---|---:|
| Media3 Transformer transmux | 13,028 ms |
| AndroidMp4TrackMuxer | 7,231 ms |

本地合并耗时下降约 44.5%。小夹具冷启动对比为 336 ms → 190 ms，方向一致。移除 Media3 合并依赖后，正式 APK 从 v1.2.5 的 91,539,663 B 降至 86,239,281 B。
