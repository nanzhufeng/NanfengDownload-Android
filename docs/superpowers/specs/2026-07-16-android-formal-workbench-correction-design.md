# 南烛枫视频下载器 Android 正式工作台纠偏设计

日期：2026-07-16  
项目：南烛枫视频下载器 Android 版  
状态：用户已要求严格按本设计执行

## 1. 纠偏结论

此前合入的 Room、Repository 与三页壳层只完成了基础设施，不是正式产品完成状态。公开首页错误地将“智能读取”跳转到旧 `ProbeScreen`，导致用户看见 Python、单视频、TikTok、抖音捕获和 Movies 写入等验证按钮。这些按钮仅用于开发期可行性验证，不能出现在正式用户流程中。

正式用户流程固定为：

```text
分享文本或链接
  -> 智能读取
  -> 正式作品列表
  -> 勾选作品与逐项分辨率
  -> 加入正式队列
  -> 下载、校验、保存
  -> 历史记录
```

不得出现第二套面向用户的解析、下载或状态真相。旧探针仅可作为内部实现的临时适配基础，不允许从首页、历史或设置公开进入。

## 2. 唯一所有者与入口

| 概念 | 唯一所有者 | 公开入口 | 禁止项 |
| --- | --- | --- | --- |
| 链接分类与作品读取 | `SourceDiscoveryEngine` | 首页“智能读取” | 页面直接调用 `ProbeViewModel` |
| 已读取作品与选择 | Room `DownloadTask` + `DownloadRepository` | 作品读取面板、队列 | UI 内部样例列表 |
| 下载执行与进度 | `DownloadEngine` | 队列中的开始、暂停、停止、批量管理 | Probe 按钮下载 |
| 历史归档 | `DownloadRepository` | 历史页 | 直接由 UI 写 DAO |
| 登录与权限摘要 | `SessionProvider` | 设置页 | 账号密码明文或公开开发入口 |

## 3. 正式首页

### 3.1 外屏，1140 × 2616 基线

严格采用已确认的工作台信息顺序：

1. 顶部：应用图标、名称与网络状态。
2. 当前下载：缩略图、标题、博主、格式、速度、进度、剩余时间、暂停、停止和全部暂停。
3. 队列：`队列 / 等待网络 / 已跳过` 三个状态标签，条目含拖动柄、序号、标题、博主、单项分辨率、大小或状态和更多操作。
4. 总进度：下载中/排队数量、百分比、总大小与“批量管理”。
5. 链接入口：位于总进度下方、底部导航上方；保留 2 至 3 行原生可长按粘贴的输入框和唯一的通栏“智能读取”。
6. 底部导航：首页、历史、设置。

无任务时必须显示诚实空状态，不得插入截图中的虚构缩略图、速度、大小或队列条目。

### 3.2 内屏，2248 × 2480 基线

- 左侧窄导航栏：品牌、首页、历史、设置、网络状态。
- 左工作栏：当前下载、总进度、多行输入、智能读取。
- 右工作栏：队列标签、可滚动条目、全选与批量管理。
- 使用窗口宽度约 600dp 作为 Find N5 内屏切换下限；不可按像素硬编码。
- 不在折痕或中间安全间距放置主操作。

## 4. 智能读取规则

- 单条 YouTube、抖音或 TikTok 视频链接只产生当前作品。
- 作者主页、YouTube 频道和播放列表才产生批量列表。
- 抖音批量结果必须以目标作者身份过滤；TikTok 必须按作者 ID 去重并剔除其他作者；不得读取推荐流。
- 已读取条目默认选中，但用户取消选择后不得进入下载。
- 单条链接不得扩展为整频道或整作者列表。
- 读取满分页批次时展示“加载更多”，而不是固定截断为 500 条。

## 5. 下载、保存与状态

- 只处理公开内容和登录后当前账号有权访问的内容；不绕过会员、付费、DRM 或私密限制。
- 任务在 Room 中持久化；活动任务、进度、选择和终态均从 Repository Flow 读取。
- 文件名为发布日期加标题，目录为 `Movies/南烛枫视频下载器/平台/博主名/`；无意义平台 ID 不进入文件名。
- 真实媒体存在、非空且通过容器校验后才能标记完成。
- 目录索引命中已存在文件时快速标记已跳过。
- 等待、下载中、完成、失败、等待网络、已跳过、已取消必须同时显示文字与语义色。

## 6. 历史与设置

- 历史只显示终态任务，提供搜索和平台/状态/博主/日期过滤；记录详情提供播放、打开所在目录、分享、复制原链接和失败重试。
- 设置只提供账号与权限摘要、默认分辨率、固定单并发、目录选择与打开、版本和内容边界。
- 抖音登录使用应用内持久 WebView Cookie；YouTube 默认公开模式，必要时导入 Netscape `cookies.txt`。
- `ProbeScreen` 和技术验证入口从正式设置页移除；内部验证能力不构成产品功能。

## 7. 验收与停止条件

### 必须通过

- 首页“智能读取”不再进入 `ProbeScreen`，也不显示任何探针按钮。
- 读取单视频、频道/作者/播放列表的分流测试通过。
- 用户取消勾选后，任务不会被调度下载。
- 外屏和内屏分别匹配本设计的信息层级，且不使用虚构下载数据。
- 任务、选择、输入草稿和历史在旋转、折叠或 Activity 重建后仍来自 Room/DataStore。
- 下载成功前经过真实文件校验；失败不能伪装成完成。

### 当前阶段不允许宣称完成

在正式 `SourceDiscoveryEngine`、`DownloadEngine`、前台下载服务、历史操作、登录与 MediaStore/SAF 均按本设计接入并完成真机验证前，不得宣称 Android 版开发完成。
