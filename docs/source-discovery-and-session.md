# 来源发现、读取与会话合同

> 合同层级：现行合同。唯一领域正文由合同总入口注册；历史方案不能覆盖本页实现事实。

2026-10-12按当前源码统一；[总入口](contracts/README.md)维护唯一性，源码/证据路径见[注册表](contracts/registry.json)。

## 所有者与入口

粘贴与分享经UrlClassifier/PlatformSourceDiscoveryEngine；平台轻量元数据、Chaquopy及网页捕获只提供来源证据。单作品、作者/频道/播放列表、合集、批次、需要捕获、失败有独立结果，不直接写DAO或宣称下载完成。当前一次最多20条不同链接；分页仍由发现引擎和来源能力决定。

平台限定官方域及目标作品/作者，B站UP主页明确拒绝。Generic接受明确HTTP(S)来源；输入带账号密码拒绝，来源身份包含完整目标范围，旧身份仅精确原URL兼容，不只按basename或主机。合集成员来源与合集页相同不代表同一作品；按实际独立来源确定身份。

## 链接输入与粘贴

2026-10-13增量：紧凑/展开首页共用ReadEntryCard，ReplaceOnPasteInput负责系统粘贴与编辑器适配，LinkInputEditing负责草稿替换。系统长按粘贴、Ctrl+V、Shift+Insert以剪贴板全文替换当前草稿，光标置末尾；空剪贴板不清空草稿。输入法剪贴板建议若一次提交包含HTTP(S)链接的文本，也以该次插入的完整分享文案/多链接替换旧草稿。非链接普通输入、删除、选区移动与IME组合态保持编辑语义，不后台读取剪贴板。

保留整段文案与换行，不截断1000字符以上内容；既有字符计数及超过1000禁用读取规则不变。草稿仍经onInputChange→HomeViewModel/Settings保存；只有文本变化才通知上层，移动光标不清发现状态。替换不自动读取、不增删已入队任务。系统分享/恢复草稿入口不受此编辑器策略影响。

参考电脑版GitHub `698f13fe661b9ab9c9f07b4900982ddf29144c0d` 的app/torrent_input.py键盘粘贴整框替换；Android补系统菜单与IME链接整段提交适配。[验证与边界](verification/2026-10-13-link-paste-replacement.md)。不同OEM输入法的正常UI行为仍需设备验证，尤其将剪贴板拆成多个组合提交的输入法。

## 读取会话与迟到结果

HomeViewModel拥有草稿与读取代次。换成不同输入会取消旧发现协程、清除旧分页/捕获/选择上下文；旧结果/超时不能改新状态，等待设置后入队前再次核对代次。同值编辑回调不取消读取，避免选区/重复回调误触发。

导航为每次抖音/通用网页捕获建立独立请求ID，Activity在成功、失败、系统返回中回传；只有当前请求可提交回调，旧成功、取消和剧集列表不能影响新请求。同作品重读也区分请求；抖音返回作品ID与目标ID/返回页再核对。请求ID只管理展示会话，不更改持久任务身份。已经提交Repository的任务不因草稿变化回滚。[审查与边界](verification/2026-10-13-input-discovery-architecture-audit.md)。

## 抖音短链连接恢复

2026-10-13增量：官方短链整条跳转链对网络IOException最多补试一次，成功路径无额外请求。取消、TLS、HTTP拒绝及来源安全拒绝不重试。持续失败按DNS/超时/连接中断返回受控短链阶段提示，内部错误详情不拼接给用户；保留目标作品身份/跳转次数与安全域校验。[依据与验收边界](verification/2026-10-13-douyin-note-shortlink-recovery.md)。这项恢复不证明任意公网/主手机读取成功。

## 可信来源与会话

- 抖音视频/图集分别使用目标环境；图集需结构化urlList、声明数、来源版本及水印URL排除。推荐、首图、任意请求不能替代完整目标证据。
- Generic动态页以用户确认可见目标播放器/iframe为准；开放Shadow DOM有扫描路径，封闭结构/任意广告请求不作为兜底。持久捕获视频与Referer有来源版本，过期按原目标刷新，不能静默换作品。
- 元数据快路径只证明目标身份/信息，下载仍经目标验证和完整媒体解析；可选字段未知不造零值。短链缓存和同次Generic快照有范围，不是永久媒体凭据。
- SessionAccessPolicy按站点与目标主机限定凭据；Cookie存在仅表示检测到会话材料，不证明真实登录/下载成功。YouTube从Netscape文件导入，其余站点有受限WebView会话入口；清除/导出仍经SessionProvider。
- 原生HLS/DASH真实传输在Python协议处理链，直链在Kotlin；两者的凭据/代理/取消边界都需验证，不再使用“Python只负责解析”的旧概括。

## 验收与差距

来源/作品/作者身份、批次部分失败、重复、官方重定向和凭据作用域有自动契约；动态页还需正常UI确认。输入/元数据/入队不等于真实成品。每次首次读取≤1秒仍是目标，历史有超标，不能由缓存命中或单样本降低目标。真实账号/网络/站点变化与访问限制单列；本轮未新跑公网或设备。
