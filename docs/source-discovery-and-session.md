# 来源发现、读取与会话合同

> 合同层级：现行合同。唯一领域正文由合同总入口注册；历史方案不能覆盖本页实现事实。

2026-10-12按当前源码统一；[总入口](contracts/README.md)维护唯一性，源码/证据路径见[注册表](contracts/registry.json)。

## 所有者与入口

粘贴与分享经UrlClassifier/PlatformSourceDiscoveryEngine；平台轻量元数据、Chaquopy及网页捕获只提供来源证据。单作品、作者/频道/播放列表、合集、批次、需要捕获、失败有独立结果，不直接写DAO或宣称下载完成。当前一次最多20条不同链接；分页仍由发现引擎和来源能力决定。

平台限定官方域及目标作品/作者，B站UP主页明确拒绝。Generic接受明确HTTP(S)来源；输入带账号密码拒绝，来源身份包含完整目标范围，旧身份仅精确原URL兼容，不只按basename或主机。合集成员来源与合集页相同不代表同一作品；按实际独立来源确定身份。

## 可信来源与会话

- 抖音视频/图集分别使用目标环境；图集需结构化urlList、声明数、来源版本及水印URL排除。推荐、首图、任意请求不能替代完整目标证据。
- Generic动态页以用户确认可见目标播放器/iframe为准；开放Shadow DOM有扫描路径，封闭结构/任意广告请求不作为兜底。持久捕获视频与Referer有来源版本，过期按原目标刷新，不能静默换作品。
- 元数据快路径只证明目标身份/信息，下载仍经目标验证和完整媒体解析；可选字段未知不造零值。短链缓存和同次Generic快照有范围，不是永久媒体凭据。
- SessionAccessPolicy按站点与目标主机限定凭据；Cookie存在仅表示检测到会话材料，不证明真实登录/下载成功。YouTube从Netscape文件导入，其余站点有受限WebView会话入口；清除/导出仍经SessionProvider。
- 原生HLS/DASH真实传输在Python协议处理链，直链在Kotlin；两者的凭据/代理/取消边界都需验证，不再使用“Python只负责解析”的旧概括。

## 验收与差距

来源/作品/作者身份、批次部分失败、重复、官方重定向和凭据作用域有自动契约；动态页还需正常UI确认。输入/元数据/入队不等于真实成品。每次首次读取≤1秒仍是目标，历史有超标，不能由缓存命中或单样本降低目标。真实账号/网络/站点变化与访问限制单列；本轮未新跑公网或设备。
